# 管理端页面数据刷新

`ops-app` 进入数据页时重新请求服务端数据。可见的销售业绩、电桩状态、电站管理和用户管理页面还会定时刷新；隐藏页面停止定时器，模态对话框打开时跳过定时刷新。

在管理端可执行文件旁创建或修改 `refresh.ini`，重启应用后生效：

```ini
[refresh]
intervalSeconds=3
```

单位为秒，默认 3 秒。缺失、非整数、非正数或会导致毫秒溢出的值均回退到 3 秒。CMake 会向管理端构建目录复制默认配置。

电站管理刷新同一电站时保留电桩选择；收到新数据后按电桩 ID 恢复选择，并根据最新状态更新操作按钮。切换电站或选中电桩被删除时清除选择。

此刷新配置仅用于 `ops-app`，不改变 `user-app` 的页面行为或充电轮询间隔。
