# 页面数据刷新

两个前端进入数据页时重新请求服务端数据。可见的列表、历史记录、个人资料和运营统计页面还会定时刷新；隐藏页面停止定时器，模态对话框打开时跳过定时刷新。

在各前端可执行文件旁创建或修改 `refresh.ini`，重启应用后生效：

```ini
[refresh]
intervalSeconds=3
```

单位为秒，默认 3 秒。缺失、非整数、非正数或会导致毫秒溢出的值均回退到 3 秒。CMake 会向两个前端的构建目录复制默认配置。充电计量轮询也使用此间隔（每次请求完成后等待）。

电站详情在进入和导航返回时刷新电桩；为避免清空正在选择的电桩，不定时重建详情列表。充电流程进入时查询活动订单，充电中由既有后台轮询更新计量。导航页在打开时重新规划路线；登录、关于等静态页面无业务数据需要轮询。
