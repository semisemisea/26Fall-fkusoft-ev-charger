# 充电桩应用管理平台（26Fall 东软实训）

覆盖"用户端—服务端—数据端"全链条的电动汽车充电桩管理平台：Qt 用户端与运营后台、biz-core 服务端、SQLite 业务库、Web 大屏、离线 ML 子系统、电桩模拟器。

## Language

### 实体

**用户 (User)**:
以 11 位手机号免密登录的车主，拥有昵称、头像、钱包余额；不存在则首次登录自动注册。_Avoid_: 顾客、账户

**管理员 (Admin)**:
运营后台的登录者（账号密码存库，默认 admin/123456），可管理桩/站/用户/订单。_Avoid_: 后台用户

**充电站 (Station)**:
地理位置上的站点，含站名、地址、经纬度、电价（元/度）、所属电桩集合。_Avoid_: 电站、站点

**电桩 (Pile)**:
具体充电设备，含编号、所属站、类型（快充/慢充）、额定功率、状态、累计次数/时长。远程重启指令的对象。_Avoid_: 充电枪、设备（泛指时）

**订单 (Order)**:
一次充电全流程的记录，状态机见下。含预约/开始/结束时间、电量、金额。_Avoid_: 交易、记录

**钱包 (Wallet)**:
用户余额，充值模拟支付成功；结算从钱包扣款。_Avoid_: 账户余额（与 User 混用时）

### 订单状态机

**预约中 (Reserved)**:
已锁定电桩未开始充电；5 分钟未开始自动转 已超时。_Avoid_: 锁定

**充电中 (Charging)**:
服务端计时计电量中；可取消，取消时按已耗电量折算金额结算。_Avoid_: 进行中

**待结算 (PendingSettle)**:
充电结束等待扣款；余额不足时停留于此并拦截新充电，可由管理员代结算。_Avoid_: 待支付

**已结算 (Settled)**:
扣款完成（含充电中取消折算的订单）。_Avoid_: 已完成、已支付

**已取消 (Cancelled)**:
用户主动放弃（预约期取消，未产生费用）。_Avoid_: 撤销

**已超时 (Expired)**:
预约 5 分钟未开始被系统释放。_Avoid_: 失效

### 桩状态

**空闲 (Idle)**:
在线且未被预约占用，可被预约。_Avoid_: 可用、在线

**预约锁 (Reserved)**:
已被订单锁定（预约中状态对应），5 分钟超时自动回空闲。_Avoid_: 锁定、占用

**充电中 (Charging)**:
正在输出电量，session 计量中。_Avoid_: 使用中、在用（"在用"是后台汇总口径=充电中）

**故障 (Faulty)**:
心跳 hw_ok=false 或指令 NAK 标记的硬件异常。_Avoid_: 坏、异常

**离线 (Offline)**:
simulator 连接断开或心跳超时。_Avoid_: 失联、不在线

（后台"电桩状态"四指标汇总口径：在用=充电中、闲置=空闲+预约锁、故障=故障、离线单列——见 env-freeze 与协议 pile.summary。**注意与用户端 station.list 的 `free` 字段区分：`free` 只数 Idle（可预约口径），后台 `idle` 是汇总口径含预约锁**）

### 机制

**加速因子 (time_factor)**:
模拟时间与现实时间比例（配置键 `time_factor`，如 60=1秒=1分钟），用于压缩充电时长便于演示，全局配置。_Avoid_: 快进、TimeFactor（英文驼峰不再用）

**计费策略 (PricingStrategy)**:
可注入的金额计算策略：FlatPricing（平价）默认；TimeOfUsePricing（峰谷）加分项。_Avoid_: 价格规则

**远程重启 (RemoteReboot)**:
ops-app 经 biz-core 向电桩下发重启指令；simulator 模拟离线数秒后恢复。_Avoid_: 重启设备（含本机含义）

**心跳 (Heartbeat)**:
simulator 周期上报硬件健康位 hw_ok（不携带占用状态，桩占用状态的权威是订单状态机）；服务端 30s 未收到心跳视桩为离线。_Avoid_: 保活、状态上报（心跳不报桩状态）

**快照接口 (Snapshot API)**:
biz-core 提供的 HTTP 接口，一次返回大屏全部指标 JSON，前端 5s 轮询。_Avoid_: 实时推送（大屏不用 WebSocket）

**告警 (Alert)**:
故障/待结算超时/设备离线等异常记录，落库供大屏告警列表展示。_Avoid_: 日志（日志是文件）
