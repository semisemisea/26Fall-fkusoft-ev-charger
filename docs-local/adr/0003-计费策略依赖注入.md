# 计费策略采用依赖注入（含峰谷定价加分项）

## 背景
说明书允许自加功能加分。基础计费：电量 = 桩额定功率 × 充电时长（服务端计时，演示用加速因子如 1秒=1分钟），金额 = 电量 × 站电价（元/度）。

## 决定
计费逻辑抽象为策略接口，biz-core 内以依赖注入方式装配：
- `FlatPricingStrategy`（平价，默认）：金额 = 电量 × 站电价
- `TimeOfUsePricingStrategy`（峰谷，加分）：按时段（峰/平/谷）套用不同费率表
- 电量与金额计算发生在服务端（状态机结算时），客户端只展示

## 理由
- 展示设计模式使用能力（考核点）+ 低成本加分项
- 策略可插拔，验收演示时可切换两种策略对比

## 后果
- 费率表需要 DB 支持（站电价字段 + 可选峰谷费率配置），schema 需预留
- 加速因子为全局配置，演示与测试共用
